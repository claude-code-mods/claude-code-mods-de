# lcu-approve

> This English reference Text was assembled von the upstream plugin manifest und catalogue metadata; the pinned upstream Commit did nicht ship a README.

Per-app approval for computer verwenden: erlauben this Gespräch, immer erlauben, oder ablehnen, plus a Bereich of genehmigt apps.

Native per-app approval for LCU computer verwenden in the Claude app und Claude Code (Allow this Gespräch, Always erlauben, Deny), und the /computer-use-apps Bereich of genehmigt apps.

## Installation

```
/plugin install lcu-approve@claude-code-mods-de
```
